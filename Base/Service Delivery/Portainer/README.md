Portainer is going to be used to control Containers.

You have to copy or rename the file `portainer.txt` as `docker-compose.yml`

It is going to be using the folder `Portainer` inside the specified path in the `.env` file. You have to specify it by copying or changing the name of the `env.example` file to `.env` and modify it.

It will also use the paths `/etc/localtime` and `/var/run/docker.sock` from your system.
